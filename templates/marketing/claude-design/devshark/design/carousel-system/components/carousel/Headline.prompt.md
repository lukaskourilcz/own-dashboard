Headline, BigNumber, Statement, Accent, Footer and Logo: the type primitives of a slide, all reading the slide's theme.

```jsx
<Headline size="short">Meet devShark.</Headline>
<Statement>A <Accent>learning platform</Accent> for web developers: lessons, <Accent>interview preparations</Accent>, quizzes, and graded coding tasks.</Statement>
<BigNumber value="€1.80" unit="a month" />
<Footer align="right" ink>Swipe →</Footer>
<Logo />
```

- The cover uses `size="cover"` and a `Statement` in the same face; no panel.
- `size="hero"` is for the one-statement slides (Every day, closing).
