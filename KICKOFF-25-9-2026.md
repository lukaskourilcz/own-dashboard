  audit, competition, UX/UI, analysis, documentation, new project from an idea, SEO,
  marketing). Prompts stay universal but tightly bound to links, so an LLM agent given a
  prompt knows which links to open.
- Career and Opportunities load only when the owner enters the section and presses
  "Zkontrolovat nové nabídky".
- Projects: `gym-plzen` and `paris-claire` go to the bottom behind a divider (freelance,
  hired); the rest are the owner's own. `aifirst` → DNESKAi, `react-express-app` → devShark,
  `quorum` → boardlessAI, on GitHub too.
- Hide Inbox (Doručené) and References (Reference).
- Every project shows the links it really uses.
- A new Tools (Nástroje) section: the tools from Links that are really in use, what each
  does and how it helps each project.

## Rules for every step

1. Inspect Git first; preserve unrelated work; coherent imperative commits with the issue number.
2. Search before creating: reuse the picker, dialog, card and token primitives; one new
   component per real gap. `AGENTS.md`: this Next.js is not the one you know — read
   `node_modules/next/dist/docs/` before route or data work.
3. Every migration: own-only RLS with parent-ownership checks in the current style, an entry in
   `docs/migration-guide.md`, hand-written types in `src/lib/types.ts` (types are not generated).
4. Keep the catch-all shell, `dashboardDataKeysForTab`, centralized query keys, `useEntityStore`,
   bounded results and invalidation on every mutation. Follow commit `b66ab79` as the template
   for a seeded entity.
5. EN/CS parity is enforced by the dictionary types; every new string has both.
6. Validate before every push: `npm run lint`, `npx tsc --noEmit`, `npm run test`,
   `npm run build`, `npm run test:e2e`; check `/dev-preview` at 360, 768 and 1280 px, light and
   dark, keyboard only, axe clean. Report exact results.
7. Do not push unless the task says so; this kickoff authorizes pushes to the issue branches.
8. Retired scope stays retired: no Pulse, habits, streaks, books, couples or lifestyle tracking;
   OwnDashboard is not renamed (`src/lib/brand.ts`).
